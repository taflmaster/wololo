# Age of Empires Sounds

Place your Age of Empires sound files in this directory.

## Expected Sound Files

The plugin looks for these sound files:
- `wololo.mp3` - Played when yanking text
- `villager-create.mp3` - Played when entering insert mode
- `villager-killed.mp3` - Played when encountering errors
- `castle.mp3` - Played when saving files
- `villager-select.wav` - Played when selecting text (visual mode)
- `campaign.mp3` - Played when opening a new file
- `drumpapappa.mp3` - Played when completing a task (e.g., exiting Neovim)

You can customize the sound mappings in the plugin configuration.
